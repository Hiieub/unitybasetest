# Dev Test

Mini-game 3D platformer vượt chướng ngại vật góc nhìn thứ 3.

## Bản Build

* **Link tải bản Build:** [Google Drive](https://drive.google.com/drive/folders/1IAdEYS8qzAsiAFhG3OVkTKGF-O0ifTNY?usp=drive_link)

## Thông tin môi trường

* **Unity Version:** `2022.3.62f2`
* **Packages:** New Input System, Cinemachine 2.10.7, TextMeshPro

## Cách điều khiển

* **Di chuyển:** `W`, `A`, `S`, `D`.
* **Nhảy:** `Space`.
* **Xoay Camera:** Giữ chuột trái và di chuyển chuột.
* **Tương tác:** Hiện UI Icon khi lại gần Cửa / Nút bấm -> Click chuột trái vào UI Icon để mở cửa / mở bậc platform.
* **Nút Reset:** Tải lại màn chơi.

## Tính năng chính

* **Gameplay:** Xuất phát từ tủ đồ phòng 1, mở cửa thông gió, vượt qua bẫy sàn và hố vực để tới đích tại phòng 2.
* **Platform thu gọn:** Bấm nút trên bục để kích hoạt mở các bậc bút chì chìa ra tạo đường đi.
* **Camera FreeLook Cinemachine:** Bám theo nhân vật theo góc nhìn thứ 3, xoay tự do bằng chuột trái và chống xuyên tường.
* **Cơ chế Thắng / Thua:** Chạm bẫy hoặc rơi xuống hố sẽ Death và dừng di chuyển; chạm đích sẽ báo Complete.
